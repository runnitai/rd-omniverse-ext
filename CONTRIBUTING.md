# Contributing

Thank you for looking. Please read this before you spend time on a change.

## This repository is a one-way mirror

The extension is developed in a private RunDiffusion repository and published
here. Every release is exported from there, so this repository is a copy of the
product rather than the place it is built.

That has one consequence worth stating plainly: **a change committed here would
be overwritten by the next export.** It is not that we would ignore it, it is
that the export replaces the tree.

## Pull requests are not accepted

We are not set up to accept code contributions, so please do not open a pull
request. Anything merged here would need porting back by hand, and we would need
a contributor agreement in place before we could take anyone's code.

This may change. If it does, this file will say so and will explain what we need
from a contributor first.

## Issues are very welcome

Bug reports and feature requests are the most useful thing you can send us, and
they do reach the developers.

A good bug report has:

- what you expected and what happened instead
- your Kit version and which Omniverse application you are running
- the extension version, shown on the panel's **Account** tab
- anything printed in the Kit console when it went wrong

If you have already worked out the fix, describe it in the issue. We will credit
you in the changelog when it ships.

## Security

Do not report a vulnerability in an issue. See [SECURITY.md](SECURITY.md).
